为什么现在"更模糊"

不是审美问题，是三条可测的规则冲突。全部在真机页面上量到：

根因 1 · CSS 撞车（标签名）

ROOT你的皮肤 blue-fantasy 自带这条全局规则：

[data-dsh-float] header { border-radius:20px; margin:12px 16px 0; padding:10px 16px 8px; backdrop-filter:blur(14px); box-shadow: …0 10px 34px }

而我的 .bp-head 正好是个 <header>。于是标题条被套上"浮动玻璃卡"，还被迫左右各缩进 16px —— 这就是标题条和模块组挤在一起、以及左右对不齐的直接原因（实测：标题条 x=327/w=899，区块 x=311/w=931）。

根因 2 · CSS 撞车（类名子串）

ROOT皮肤还有 [data-dsh-float] [class*="card"] { border-radius:14px }。我的类名全含 card 子串，被整体命中 —— 卡片自己的 12px、身份块 8px 圆角全被强行改成 14px，形状发糊。

根因 3 · 玻璃被皮肤染色

ROOT卡面是 rgba(255,255,255,.9→.56) 且没有模糊，皮肤的青绿直接透进来（实测卡面 #cfeef0），壁纸点阵还形成噪点。

实测对比度（当前）

卡片名称 #628692 / 卡面3.21 : 1
卡片描述 #6cceca / 卡面1.51 : 1
WCAG AA 正文门槛4.5 : 1

描述文字 1.51:1 基本等于看不见——"找不到卡片"主要死在这里，不在配色。

建议怎么改

  • FIX标题改用 <div>（避开 header 规则），并在样式表里做一次防御性重置。→ 左右 16px 错位消失。
  • FIX类名 bp-card* 改名 bp-tile*（避开 class*="card"）。→ 圆角恢复自己的值。
  • FIX卡面改"磨砂"：rgba(255,255,255,.80) + blur(20px) saturate(.42)。→ 保留透明感，但把青绿滤成柔灰白，噪点消失。
  • FIX字阶：名称 14/600 近黑；描述 12.5/300 中灰、固定两行高（同行卡片页脚对齐）。
  • FIX颜色只留一个含义：身份色块；状态改为 仅异常才上色边（正常不再染边），去掉满页绿边。
  • FIX单一口径对齐：--gutter 一个变量贯穿标题与所有区块。
  • FIX服务卡的"描述位"目前放的也是状态词，于是同一句渲染两遍（正文一次、胶囊一次）。建议正文让位给胶囊。
